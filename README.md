# Weed Species Classification (TÜBİTAK 2209-A)

This project contains Python scripts developed to train deep learning models for weed species classification using both internet-collected images and a primary greenhouse dataset.

### Project Note
This work was carried out as part of a TÜBİTAK 2209-A project. For this reason, the evaluation graphs were originally generated in Turkish. The methods and findings are summarized in English in the project report.

### Files
* `Classification With Deep Learning/` – Model training and evaluation code.
* `2209-A_TÜBİTAK_Results.docx` – Complete project results and analysis.
